# User Guide

The planned interface is a menu-driven command-line application.

1. Start with `absuite` or `python -m absuite.main`.
2. Select sorting, searching, all benchmarks, profiling, or graph generation.
3. Choose dataset types and input sizes when prompted.
4. Inspect CSV files under `output/raw/`.
5. Inspect GNUplot graphs under `output/graphs/` and profiling reports under `output/profiles/`.

Some menu options are scaffolded and will become functional as implementation progresses.
